# Employee Analytics Dashboard

A professional analytics dashboard built using React, AG Grid and Recharts.

## Features

* Employee KPI Overview
* Total Employees
* Active Employees
* Average Salary
* Average Performance Rating
* Department Distribution Chart
* Salary Distribution Chart
* AG Grid Data Table
* Global Search
* Department Filtering
* CSV Export
* Dark / Light Theme
* Responsive Design

## Tech Stack

* React
* JavaScript
* AG Grid Community
* Recharts
* CSS3
* Vite

## Installation

```bash
npm install
npm run dev
```
